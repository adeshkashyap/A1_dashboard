# EstateFlow — Real Estate CRM UI Demo

A polished React dashboard template for real-estate dealers and agencies.  
Everything runs in the browser with **localStorage + seeded dummy data** — no backend, Supabase, or API keys.

## Features

- Marketing landing page
- One-click demo login
- Dashboard KPIs, leads kanban, properties, clients, team, WhatsApp (mock), automation, reports, settings
- Create / edit / delete persists in `localStorage`

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) → **Try Demo** / **Login** → **Enter Demo Dashboard**.

## Stack

- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- TanStack Query + Framer Motion + Recharts
